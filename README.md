# rust-pilot

The first project in Sweet Potato's strict `rust-service` lane. It proves the lane's checks on a small command-line tool before the same setup becomes a template for new projects.

```text
$ rust-pilot stage-1-supervised
stage-1-supervised: one builder runs while Et inspects every step
```

The tool reports what a builder may do at each trust stage. It is a placeholder domain: a project made from this template replaces `src/` and keeps the rest.

See [AGENTS.md](AGENTS.md) for the rules and how to prove a change.
